# 莫高窟户外气象预报 + 窟内微环境与壁画盐害风险：数据集与数据管线方案

> **目标站点**：甘肃敦煌 莫高窟（Mogao Grottoes），约 **40.04°N, 94.81°E**，海拔约 1130–1140 m（敦煌市区 1139 m）
> **任务**：24/48/72 h 户外气象预报 → 窟内微环境反演 → 壁画盐害（酥碱/疱疹）风险指数
> **本方案所有 URL / 数据集 / 站号 / 参数均经实际抓取验证**；标记 ✅ = 已实测，⚠️ = 部分验证/有重大限制，❌ = 未能验证（勿当作事实使用）

## 0. 执行摘要：五条必须知道的结论

1. **✅ NASA POWER 是唯一"零门槛 + 逐小时 + 2001→现在 + 免注册"的户外驱动源。** 实测 endpoint 可直接 `curl` 拉取，JSON/CSV/NetCDF 均可。但其数据源是 **MERRA-2 再分析**（API 响应头 `"sources": ["MERRA2","POWER"]`），**不是观测**。且它返回的格点海拔是 **1639.24 m**，比莫高窟实际高约 **500 m** —— 直接用会导致气压、气温系统性偏差，必须处理。
2. **❌ 网上流传的"敦煌站号 52618"是错的。** 经 NOAA ISD 台站表实测：敦煌的正确站号是 **WMO 52418 / USAF 524180 / GHCN `CHM00052418`**（40.150°N, 94.683°E, **1140 m**）。而 `526180` 是 "DANGCHENGWAN SOUTH"（当城湾南，39.167°N, 94.833°E, 3746 m），**只有 1962-03-02 至 1962-04-30 两个月的数据**。用错站号会得到完全错误的结果。
3. **⚠️ 敦煌站观测数据在 2023-04-28 之后断了。** NOAA ISD 中敦煌只有 3 小时一次（SYNOP）的记录，且 2023 年文件止于 **2023-04-28T03:00**。周边站（酒泉 525330、张掖 526520、冷湖 526020、玉门镇 524360）仍更新至 2025-08。**所以 2023-05 之后的"真值"没有免费观测可用**，只能靠 ERA5/POWER/TPDC。
4. **✅ 存在一个真实的敦煌本地高分辨率观测数据集（TPDC）**，但**不在莫高窟**：兰州大学 CARN 敦煌站位于 **敦煌西湖（93.709°E, 40.348°N, 993 m），下垫面为湿地，距莫高窟约 110 km**，30 min 分辨率，2019/2020/2021 三年，DOI `10.11888/Meteoro.tpdc.270798` 等。**并且 2019 年的空气湿度字段官方标注"由于程序故障，空气湿度采集错误"** —— 做湿度相关任务时 2019 年不可用。
5. **❌ 莫高窟窟内温湿度没有公开数据集。** 但**存在真实可用的替代/类比洞窟数据集**：**ICCP（以色列洞穴气候计划）**，12 个岩溶洞穴（含 **Desert 荒漠带**）、**逐小时气温 + 相对湿度**、42 个记录仪、2019–2021，NetCDF 开放下载（Zenodo `10.5281/zenodo.17505739`）。这是本项目生成窟内目标最可靠的"真实锚点"。

## 1. NASA POWER（✅ 全部实测，含实际抓取）

### 1.1 Endpoint 与可用语法

**实测可用的逐小时点请求 URL（已 200 OK 返回真实数据）：**

```
https://power.larc.nasa.gov/api/temporal/hourly/point?parameters=T2M,RH2M,PRECTOTCORR,WS10M,WD10M,PS,ALLSKY_SFC_SW_DWN,T2MDEW&community=RE&longitude=94.81&latitude=40.04&start=20240101&end=20240103&format=JSON
```

Python 最小可跑示例（已按实测响应结构编写）：

```python
import requests
URL = "https://power.larc.nasa.gov/api/temporal/hourly/point"
p = {
    "parameters": "T2M,T2MDEW,RH2M,PRECTOTCORR,WS10M,WS2M,WD10M,PS,ALLSKY_SFC_SW_DWN",
    "community":  "RE",          # RE=Renewable Energy, AG=Agroclimatology, SB=Sustainable Buildings
    "longitude":  94.81, "latitude": 40.04,
    "start": "20240101", "end": "20240103",
    "format": "JSON",            # JSON | CSV | ASCII | NetCDF | EPW
    "time-standard": "UTC",      # 默认 LST（局地太阳时），做 ML 必须显式指定 UTC
}
r = requests.get(URL, params=p, timeout=120)
data = r.json()["properties"]["parameter"]["T2M"]   # {"2024010100": -6.07, ...}
```

**实测响应结构（真实抓取结果）：**

```json
{"type":"Feature",
 "geometry":{"type":"Point","coordinates":[94.81, 40.04, 1639.24]},
 "properties":{"parameter":{
    "T2M":{"2024010100":-6.07,"2024010101":-6.44, ...},
    "RH2M":{"2024010100":43.2, ...},
    "PRECTOTCORR":{"2024010100":0.0, ...},
    "PS":{"2025060100":83.07, ...}}},
 "header":{"title":"NASA/POWER Source Native Resolution Hourly Data",
           "api":{"version":"v2.10.2","name":"POWER Hourly API"},
           "sources":["MERRA2","POWER"],
           "fill_value":-999.0,
           "time_standard":"LST",
           "start":"20240101","end":"20241231"}}
```

> **注意 `coordinates` 第三个分量 `1639.24`** —— 这是 POWER/MERRA-2 给出的格点海拔，**远高于莫高窟实际的约 1140 m**（MERRA-2 原生分辨率 0.5°×0.625°，格点内包含周边山地）。下文 1.5 给出处理办法。

### 1.2 已实测可用的参数（全部返回 200 + 真实数值）

| 参数 | 含义 | 单位 | 实测样例值 |
|---|---|---|---|
| `T2M` | 2 m 气温 | °C | 2024 全年 min −14.9 / max **38.14** |
| `T2MDEW` | 2 m 露点温度 | °C | 2025060100 = −4.43 |
| `RH2M` | 2 m 相对湿度 | % | 2024 全年 min **3.07** / max 100 |
| `PRECTOTCORR` | 校正降水 | mm/hour | 2024 全年累计 **63.34 mm**，max 3.12 mm/h |
| `WS10M` / `WS2M` | 10 m / 2 m 风速 | m/s | 2025060100 WS2M = 2.06 |
| `WD10M` | 10 m 风向 | 度 | 2025060100 = 82.8 |
| `PS` | 地面气压 | kPa | 2025060100 = **83.07 kPa**（即 830.7 hPa） |
| `ALLSKY_SFC_SW_DWN` | 全天空短波下行辐射 | kW·h/m²/day（逐小时为瞬时均值） | 已请求成功 |

**对窟内微环境建模真正关键的补充参数**（同 API，建议一并取）：
`T2MWET`（湿球温度）、`QV2M`（比湿）、`U10M`/`V10M`（风矢量分量，比 WS/WD 更好入模）、`ALLSKY_SFC_LW_DWN`（长波下行，**窟壁热平衡必需**）、`CLRSKY_SFC_SW_DWN`（晴空辐射，用于算云衰减）、`T2M_RANGE`、`TOA_SW_DWN`。

### 1.3 时间范围、上限、延迟（✅ 官方文档 + 实测双重确认）

- **历史起点**：**2001-01-01**。官方文档原文："Hourly UTC and LST time standards data are available from **2001/01/01** to Near Real Time (NRT)"。
  **实测交叉验证**：`start=19810101` / `19840101` / `19900101` 全部返回 **HTTP 422**；`start=20010101` 返回 **200**。**所以"1950 年起"之类的说法对逐小时接口不成立，只能从 2001 年开始。**
- **末端**：Near Real Time（NRT）。**实测 2025-09-01~03 有完整数据**，说明延迟在数天量级（POWER 官方文档未给出精确小时数，⚠️ 未逐字核实具体延迟天数，建议以 `end = today − 5d` 保守回退）。
- **单次请求上限**：**最多 15 个参数**（官方文档明确："A maximum of 15 parameters can currently be requested in one submission"）。
- **时间标准**：默认 **LST（Local Solar Time）**，⚠️ 官方明确警告 "may not match the actual local time zone as assigned by the location's government"。**对敦煌（94.81°E，UTC+6 名义 / 中国标准时 UTC+8）必须显式传 `time-standard=UTC`**，否则与中国本地时间、与 CMA/ISD 观测对不上，会造成 2 小时以上的系统性错位。
- **填充值**：`-999.0`（响应头 `fill_value`）。

### 1.4 速率限制与许可（⚠️ 部分未能验证）

- **速率限制**：❌ **未能找到 POWER 官方公布的数值化 rate limit（如 X 次/小时）**。官方文档只给出"单次 ≤ 15 参数"。实测连续多次请求未触发限流。
  **工程建议**：按 **≤ 1 请求/秒、带指数退避重试、结果落盘缓存** 来做，这足以满足本项目（敦煌单点 2001–2025 逐小时 ≈ 22 万条，分年拉取仅需约 25 次请求）。
- **许可/引用**：✅ POWER 是 NASA LaRC 的**免费公开服务**，无需注册、无需 API key。⚠️ 但本次**未抓取到一份明确的"必须逐字引用"的官方许可条款页面**。
  **保守做法（强烈建议）**：在报告中按 NASA 惯例引用：
  > *"These data were obtained from the NASA Langley Research Center (LaRC) POWER Project funded through the NASA Earth Science/Applied Science Program."*
  并附上 `https://power.larc.nasa.gov/` 与访问日期。**团队提交前应人工打开 POWER 官网的 "Data Access / Citation" 页面核对当年最新措辞。**

### 1.5 ⚠️ 必须处理的两个坑

**坑 1：格点海拔 1639 m ≠ 实际 1140 m。**
API 返回的 `PS` 是 **格点海拔上的气压**（实测 2025-06-01 为 830.7 hPa）。莫高窟实际海拔约 1140 m，同一时刻真实气压应在 **~880 hPa** 量级。**500 m 的落差会带来约 5–6 kPa 的气压偏差和可感知的气温偏差。**
**解决办法（官方支持）**：POWER 逐小时 Point 接口支持 **`site-elevation`** 参数（官方文档："If you wish to pass your own site elevation (in meters), you will receive a **corrected atmospheric pressure** value upon adjustment to the elevation you provided"）。**务必传 `site-elevation=1140`**（或更精确的窟区实测高程）重新拉取 PS。同时，`wind-elevation`（10–300 m）可用于把风廓线调整到窟檐/崖面高度。
**此外**：T2M 本身也受格点海拔影响（MERRA-2 格点平均海拔偏高 → 气温偏低）。**建议对 T2M 做一次以 ISD/TPDC 实测为基准的偏差订正（bias correction）**，而不是直接使用。

**坑 2：`PRECTOTCORR` 是再分析订正产品，不是观测。**
API 响应头明确列出 `"sources": ["MERRA2","POWER"]`，标题为 "Source Native Resolution Hourly Data"。`PRECTOTCORR`（Precipitation Total Corrected）是基于 **MERRA-2 再分析**的偏差订正降水，**不是雨量计观测**。
- 对敦煌这种超干旱区，**降水信号极弱**：实测 2024 全年仅 **63.34 mm**，且大量小时为 0（最大 3.12 mm/h）。
- 文献与官方宣传材料给莫高窟年降水约 **25 mm**（Campbell Scientific 莫高窟案例研究原文："annual rainfall 25 mm"），与 POWER 的 63 mm 有量级内的差异 —— **这正说明不同产品的降水口径差异巨大**。
- **结论**：降水这一目标变量在敦煌**信噪比极低、且无免费真值可验证**。⚠️ **不要把"降水预测精度"作为项目的核心指标**，否则评委会质疑可验证性。建议降级为辅助特征，或改为"降水事件二分类（有/无）+ 不确定性区间"。

**对本项目的定位**：
- ✅ **ERA5-Land 的 4 层土壤温度/土壤湿度是本项目的隐藏王牌** —— 莫高窟是崖壁开凿的洞窟，**窟内热惯性本质上就是"岩体作为半无限固体的导热问题"**，而 ERA5-Land 提供了真实的地表能量与土壤热状态边界条件，比只用气温做驱动强得多。
- ⚠️ 但 ERA5-Land **不包含 10 m 风、海平面气压等大气变量**（它是陆面分量重放），风速/气压必须从 `reanalysis-era5-single-levels` 取。两套 0.25°/0.1° 网格需要插值到同一分析格点。
- **官方推荐请求代码骨架（✅ 官方示例改写，字段名均已核对）**：

```python
import cdsapi
c = cdsapi.Client()
c.retrieve('reanalysis-era5-single-levels', {
    'product_type': ['reanalysis'],
    'variable': ['2m_temperature', '2m_dewpoint_temperature',
                 'surface_pressure', 'mean_sea_level_pressure',
                 '10m_u_component_of_wind', '10m_v_component_of_wind',
                 'total_precipitation', 'surface_solar_radiation_downwards',
                 'surface_net_solar_radiation', 'total_cloud_cover',
                 'boundary_layer_height'],
    'year': ['2024'], 'month': ['01'], 'day': ['01'],
    'time': [f'{h:02d}:00' for h in range(24)],
    'area': [40.30, 94.60, 39.80, 95.00],   # N, W, S, E  ← 顺序易错，务必核对
    'data_format': 'netcdf',
}, 'dh_20240101.nc')
```
> ⚠️ **`area` 顺序是 `[North, West, South, East]`**（左上右下），这是官方文档的标准约定；`time` 用 `"HH:00"` 字符串列表。⚠️ **本次未实测该请求能真正跑通**（需要账号 + Token + 手工同意 Licence，本会话无凭据），**变量名字符串来自官方示例与目录页，请团队首次运行时用 CDS 网页"Show API request code"按钮生成的代码为准**。
> ⚠️ **`2m_relative_humidity` 在 ERA5 single levels 中通常不存在**，需由 `2m_temperature` + `2m_dewpoint_temperature` 自行用 Magnus 公式推导。此点请以 CDS 下载表单实际勾选项为准。

**许可与引用（✅ 数据集页显示 CC-BY；⚠️ 逐字归属声明建议再核）**
> *"Generated using Copernicus Climate Change Service information [year]"* —— ⚠️ 本次**未从 Copernicus 官方许可页逐字核实该句**，请团队在提交前到 Copernicus Licence 页面核对当年要求的确切措辞。CC-BY 一般还要求列出数据集 DOI 与 ECMWF/C3S 作为来源。

### 3.2 空间设置：单点 vs 多点网格

**不要只用单点。** 建议 **"1 个中心点 + 两层环状网格"**：

```

- **外层作用**：捕捉河西走廊西段的**区域环流**（西风带、蒙古高压南缘、局地山谷风），这是单纯单点无法提供的物理信息。

### 3.3 窟内（in-cave）目标如何构建 —— 诚实的做法

**核心前提（必须写进报告第一段）：莫高窟窟内温湿度无公开数据，任何"窟内真值"都是模型生成的，不是观测。**

在**不伪造数据**的前提下，有三种可辩护的路线。推荐 **A + B 组合**，C 作为加分。

---

#### 方案 A：文献参数化的集总热/湿平衡模型（lumped heat & moisture balance）★推荐主线

**物理内核**：把窟内空气 + 壁面表层视为一个集总体，与户外经"岩体导热 + 洞口通风"两条路径交换热量与水分。

**(A1) 纯导热路径 —— 半无限固体一维热传导解析解**

对表面施加正弦强迫，深度 z 处的温度：

```
T(z,t) = T̄ + A₀ · exp(−z/δ) · sin(ωt − z/δ)
其中  δ = sqrt(2α/ω)              （阻尼深度 damping depth）
      振幅衰减  A(z)/A₀ = exp(−z/δ)
      相位滞后  Δt = z · sqrt(1/(2αω)) = z/(2α) · ... （以弧度计相位 = z/δ）
```
**关键参数 α（热扩散率 thermal diffusivity）—— 唯一有真实文献支撑的取值：**

> **α = 5.07 × 10⁻⁷ ± 1.27 × 10⁻⁷ m²/s**
> 来源：**Domínguez-Villar, D., Krklec, K., Sierro, F.J. (2023). "Thermal conduction in karst terrains dominating cave atmosphere temperatures: Quantification of thermal diffusivity." *International Journal of Thermal Sciences* 189, 108282. DOI: `10.1016/j.ijthermalsci.2023.108282`**（✅ 已下载全文并核对原文）
> 原文关键结论：① 该值由西班牙 Los Pilones 洞 **5 年温度记录**反演，1-D 热传导模型可解释**高达 94%** 的洞内温度变率；② 衰减与相位滞后同基岩覆盖厚度**强相关（两者 r² = 0.95）**；③ 该值落在**碳酸盐岩实验室测定值范围内**；④ 原文明确："**Daily temperature cycles are typically attenuated within ~2 m, thermal anomalies of seasonal cycles are muted below depths of c. 20 m**"。

**⚠️ 重大注意：莫高窟是砾岩/砂岩（conglomerate grading to sandstone），不是碳酸盐岩。** 砂岩 α 通常高于灰岩。**不得直接套用 5.07×10⁻⁷**，应把它作为**下界**，并以 α ∈ [0.8, 1.5]×10⁻⁶ m²/s 做敏感性分析（此区间为工程惯例区间，⚠️ **本次未取到砂岩 α 的一手文献**，团队须自行补一篇砂岩/砾岩热物性文献，例如岩土热物性手册或 LI-6 导热仪实测）。

| 2 m | 0.412 | 51.5 d | 4.4×10⁻⁸ |
| 5 m | 0.109 | 128.8 d | ~10⁻¹⁹ |

阻尼深度：**日周期 11.8 cm，年周期 2.26 m**（α=5.07e-7）；若取砂岩 α=1.2e-6，则为 **18.2 cm / 3.47 m**。

> **❗ 这里有一个必须写进报告的重要科学发现**：纯导热模型预测，覆盖 10 m 的洞窟**年振幅只有地表的 1.2%、滞后超过 8 个月**。但莫高窟这类**带窟门、有游客、与外界连通的旅游洞窟**，实测普遍存在明显的季节变化 —— **说明纯导热无法解释，必须引入通风/平流项**。这既是本方案的技术要点，也是团队展示物理洞察力的绝佳素材。

**(A2) 通风/平流路径 —— 集总空气交换**

```
dT_in/dt = (1/τ) · (T_eff − T_in) ,   τ = V / (ACH · V) = 1/ACH
```
- **ACH（air changes per hour，换气次数）** 是核心参数。⚠️ **本次未取到莫高窟 ACH 的实测值**，须由团队补文献（石窟/洞窟换气率、示踪气体或 CO₂ 质量平衡法）。
- **物理约束**：通风强度由 **窟内外温差**（热压驱动）与**风速**（风压驱动）共同决定，因此可写成
  `ACH(t) = a·|ΔT(t)| + b·WS(t)^n`（n≈1，风压通风）。**这正好把户外预报的风与温度显式接入窟内模型 —— 是"户外预报 → 窟内推断"链条的物理落点。**
- **ICCP 数据集的作用在此体现**：用 12 个洞窟的逐小时 T/RH 拟合 (A1)+(A2) 的参数分布，验证函数形式，再把形式迁移到莫高窟。

**(A3) 湿平衡路径**
窟内绝对湿度 `ρv_in` 同样做集总平衡：通风带入户外水汽 + 壁面吸附/解吸 + 凝结/蒸发。**相对湿度由 `RH_in = f(ρv_in, T_in)` 反算**（Magnus/Tetens 公式）。这在物理上很重要：**即使绝对湿度不变，窟内降温也会导致 RH 上升甚至结露** —— 这正是盐害的关键触发路径。

#### 方案 B：一阶衰减 + 滞后传递函数（first-order attenuation + lag transfer function）★推荐作为基线

把 (A1) 的解析解直接当作**可学习的一阶（或二阶）线性时不变系统**：

```
T_in(t) = a₀ + Σₖ wₖ · T_out(t − τₖ) ,   k = 1..K,  τₖ ∈ {0, 1, ..., 720} h
```
- 用 ICCP 荒漠带洞穴数据**拟合 w 与 τ**，得到实测的衰减系数与最优滞后；
- 再以 (A1) 的理论值作为**先验约束**（例如正则项把总权重和的量级约束在 `exp(−z/δ)` 附近，把重心滞后约束在 `z·sqrt(1/(2αω))` 附近）。
- **优点**：极其简单、可解释、参数少、不易过拟合，**作为主模型的 baseline 极其合适**；也满足评委对"可解释性"的偏好。
- **学术支撑（✅ 已核对原文标题与出处）**：Rau, G.C., Cuthbert, M.O., Andersen, M.S., Baker, A., Rutlidge, H., Markowska, M., Roshan, H., Marjo, C.E., Graham, P.W., Acworth, R.I. (2015). "Controls on cave drip water temperature and implications for speleothem-based paleoclimate reconstructions." *Quaternary Science Reviews*. DOI: `10.1016/j.quascirev.2015.03.026`（CC BY-NC-ND）。

#### 盐害风险指数（salt-weathering risk index）

**✅ 有真实中文一手文献支撑莫高窟盐害机理：**

> 胡红岩, 陈港泉, 钱玲, 容波, 靳治良, 周铁, 苏伯民, 吕功煊. **《NaCl盐的结晶形态及在莫高窟壁画疱疹病害中的作用》**. **自然杂志 (Chinese Journal of Nature), 2016, 38(1): 39–44.** DOI: `10.3969/j.issn.0253-9608.2016.01.006`
> 作者单位：中科院兰州化学物理研究所（羰基合成与选择氧化国家重点实验室）、**敦煌研究院保护研究所 / 国家古代壁画保护工程技术研究中心**、秦始皇帝陵博物院
> ✅ **已下载全文并核对原文**，关键结论：
> - 莫高窟**70 多个窟**存在严重壁画病害（颜料脱落、起甲、**疱疹**、**酥碱**、褪色、霉变）
> - **可溶盐主要为 NaCl、Na₂SO₄、CaCl₂；微溶盐为 CaSO₄**
> - **NaCl 结晶是形成疱疹病害的主因**；**只要有少量 Na₂SO₄ 共存，破坏速度与程度就大幅加剧**
> - 疱疹直径 1–3 mm，高 1–2 mm
> - 机理：Na₂SO₄ 结晶/水合物收缩孔隙，降低 NaCl 结晶对孔隙的局限压
> - 引用链（真实文献，可作为团队的二次文献来源）：Zehnder & Arnold (1988), *J. Crystal Growth* 97(2): 513-521；Rodriguez-Navarro & Doehne (1999)；郭宏、李最雄等《敦煌莫高窟壁画酥碱病害机理研究》之一/之二/之三，《敦煌研究》1998(3):153-163、1998(4):159-172、1999；张明泉、张虎元、曾正中等《敦煌壁画盐害及其地质背景》，敦煌研究文集·石窟保护篇(上)，1993:16-34

**推荐的盐害风险指数设计（物理上可辩护的形式）：**

```
SaltRisk(t) = Σ_s  w_s · [ 1{RH_in(t) 跨过 DRH_s} + λ · 1{RH_in(t) 长时间 > RH_crit} ]
                +  κ · N_cycles(ΔT 跨越 32.4 °C, 芒硝↔无水芒硝 相变)          ← 权重更高
                +  μ · TimeOfWetness(窟内壁面结露时长)
```
- **NaCl 潮解点 DRH ≈ 75.3% @25 °C；Na₂SO₄ 的 thenardite↔mirabilite 转变在 ~32.4 °C 附近** —— ⚠️ **本次未从一手文献逐字核实这些数值**。团队**必须**自行从原始文献核对（建议优先查阅上面引用的 Zehnder & Arnold 1988、Rodriguez-Navarro & Doehne 1999，以及 "Hygroscopic properties of salt-containing earthen plasters in the Mogao Grottoes: an experimental study" 这类莫高窟专门实验研究）。
- **核心物理洞察（务必写进报告）**：敦煌户外年均 RH 极低（POWER 实测 2024 年最低 3.07%），**但窟内因岩体保温、通风受限、游客呼出水汽，RH 可长期维持在远高于户外的水平**。因此 **"盐害风险 ≠ 户外湿度"**，风险来自 **窟内 RH 在潮解点附近的往复跨越次数（cycling）**，而非绝对湿度。这正是"户外预报 → 窟内推断 → 风险指数"三级链条的价值所在。

### 3.4 如何在竞赛报告中诚实呈现（避免"看起来像编造"）

**核心原则：把"数据缺失"本身变成一个被明确声明、被量化、被讨论的研究贡献，而不是一个隐藏的假设。**

必写的四条声明（建议放在"数据与方法"开篇，用小节"3.1 数据可得性与局限声明"）：

1. **显式声明窟内无公开观测。**
   > "经检索 figshare / Zenodo / Scientific Data / ESSD / 国家青藏高原科学数据中心 / 甘肃省科学数据中心 等公开库，**未发现莫高窟或其他中国石窟的窟内温湿度公开时间序列数据集**。莫高窟自 1990 年起由 Getty Conservation Institute 与敦煌研究院开展窟内 RH/气温/壁面温度/CO₂ 监测（Campbell Scientific CR10 系统，6 个洞窟），但**数据未公开**。因此本项目窟内目标为**物理模型生成的合成标签（physics-derived synthetic labels）**，非实测观测。"

2. **明确给"目标变量"改名。**
   不要叫 `cave_temperature_truth`，要叫 **`cave_T_physical_estimate`** 或 **`cave_T_model_derived`**。**变量命名本身就是诚信声明。** 报告中所有图表 y 轴标注 "model-derived"。

3. **声明参数来源与不确定性。**
   每个物理参数（α、ACH、壁面换热系数、DRH）都给出：**数值 / 文献出处 DOI / 适用岩性或气候条件 / 为什么适用于莫高窟 / 不适用之处**。例如：
   > "本文取 α = 5.07×10⁻⁷ m²/s 作为碳酸盐岩参考值（Domínguez-Villar et al., 2023, DOI:10.1016/j.ijthermalsci.2023.108282）。**但莫高窟崖体为胶结较差的细粒砾岩向砂岩过渡（Campbell Scientific, AP No.014），其热扩散率应高于碳酸盐岩**，故本文以 α ∈ [5.07×10⁻⁷, 1.5×10⁻⁶] m²/s 做敏感性分析，并报告该区间导致的窟内温度预测包络。"

4. **用 ICCP 做外部效度验证。**
   > "本文的户外→窟内传递函数形式在 **ICCP 以色列洞穴气候计划数据集（Zenodo, DOI:10.5281/zenodo.17505739）** 的 12 个岩溶洞穴（含 Desert 气候带）逐小时 T/RH 实测上做了标定与留一洞穴交叉验证，R² = …。该数据集与莫高窟岩性不同，但同属**干旱/半干旱区洞穴**，可支持传递函数形式的外部效度。"

5. **主动列出"已知不可验证项"清单**（放附录）。例如：2023-05 后无敦煌站点真值；莫高窟无 ACH 实测；盐类 DRH 取自文献而非窟内实测。**主动暴露局限的团队，比装作没有局限的团队可信得多。**

### 4.2 什么会构成"成果相关数据、案例等内容真实可靠"规则下的**失实（misrepresentation）**

**红线（一旦触碰即属造假）：**

1. **❌ 把合成/模型生成的窟内数据标注为"实测"或"观测"。**
   例如：图表写 "窟内实测温度"、变量名用 `observed_cave_T`、正文写"监测数据显示窟内年平均温度为 X"。**这是最典型也最致命的失实。**
2. **❌ 编造不存在的监测数据、数据集、DOI 或站号。**（本项目已发现"52618"这一流传的错误站号 —— **使用它并在报告中称其为敦煌站，即构成事实性错误。**）
3. **❌ 声称使用了实际未能获取的数据。**
   例如：写"使用了敦煌研究院 1990–1995 年窟内监测数据"，而实际从未获得授权。**要么拿到授权并注明授权文件，要么明确写"该数据未公开，本项目未能获取"。**
4. **❌ 把再分析产品当观测真值。**
   例如：把 POWER 的 `PRECTOTCORR` 称为"敦煌降水观测"，或把 ERA5 称为"实测气象数据"。**必须写 "reanalysis"**。
5. **❌ 隐藏关键失效区间。**
   例如：宣称"2015–2025 全时段验证"，而实际 2023-05 之后无任何真值。**必须在图表上标出无验证区间（灰色阴影），并在正文说明。**
6. **❌ 跨距离/跨下垫面迁移数据而不声明。**
   例如：用敦煌西湖（湿地，距窟 110 km）的 RH 代表莫高窟户外 RH 而不加任何说明。
7. **❌ 虚构文献引用或错误归因参数。**（例如把碳酸盐岩的 α 说成是"砂岩实测值"。）
8. **❌ 在无授权的情况下再分发第三方受限数据**（CMA 数据、可能的地面实测数据）。

**合规（推荐做法）：**

- ✅ **术语纪律**：全文严格区分 `observation` / `reanalysis` / `model-derived` / `synthetic`，每个数据集标注其类别。
- ✅ **图表纪律**：模型生成的目标变量在图例与 y 轴一律标 `model-derived`；无真值区间用灰底标注。
- ✅ **参数纪律**：每个物理常数都带 DOI 与"适用条件"说明。
- ✅ **可复现纪律**：提供完整的数据获取脚本（含 API 调用参数）与随机种子；**让评委能一键复现数据管线** —— 这是"真实可靠"的最强证明。
- ✅ **数据可得性声明**：单列一节"数据可得性与局限"，主动列出所有未获取到的数据和原因。
- ✅ **主动申请**：尽早以正式函件向**敦煌研究院保护研究所 / 国家古代壁画保护工程技术研究中心**申请窟内监测数据。**即使被拒，在报告中写明"已申请，截至提交日未获授权"，也是诚信加分项。**
- ✅ **伦理**：莫高窟为 UNESCO 世界文化遗产。任何涉及窟内环境的结论都应**附"仅用于科研，不构成保护工程建议"的免责声明**；不得发布可能被解读为"某窟即将损坏"的未经证实结论。

```bash
# 1) 户外驱动：NASA POWER，2001→今，UTC，修正到真实海拔
#    注意 time-standard=UTC 与 site-elevation=1140
for Y in $(seq 2001 2025); do
  curl -s "https://power.larc.nasa.gov/api/temporal/hourly/point?\
parameters=T2M,T2MDEW,T2MWET,RH2M,QV2M,PRECTOTCORR,WS10M,WS2M,WD10M,U10M,V10M,PS,\
ALLSKY_SFC_SW_DWN,ALLSKY_SFC_LW_DWN,CLRSKY_SFC_SW_DWN&\
community=RE&longitude=94.81&latitude=40.04&start=${Y}0101&end=${Y}1231&\
format=CSV&time-standard=UTC&site-elevation=1140" -o "power_dh_${Y}.csv"
  sleep 1
done
# ⚠️ 单次 ≤15 参数，上面正好 15 个；要更多请分批

# 2) 真值校验：敦煌 ISD（1956→2023-04-28）
