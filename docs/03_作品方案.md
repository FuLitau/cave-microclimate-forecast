# 石窟天盾：风险对齐的窟内微气候预报

**参赛主题**：智慧气象 · 方向二（气象数据赋能行业应用）
**作品名称**（17 字）：石窟天盾：风险对齐的窟内微气候预报

---

## 作品简介（293 字）

石窟壁画盐害由湿度超阈的累积时长触发。现有洞窟微环境研究均以均方误差为训练目标，导致模型平均意义上精确、风险意义上失效——实测 MSE 训练下窟内 RH 的 R² 达 0.42，超阈事件 F1 却恒为 0.000。本项目重构为风险对齐预报：用延迟嵌入 Koopman 输运算子（闭式解、可微、可解释）把室外气象轨迹映射为窟内湿度风险，并以阈值加权评分规则 twCRPS 替代 MSE 训练。超阈 F1 由 0→0.122、AUC 由 0.781→0.875，点精度不降反升；24 h 预警检出率 34%、平均提前 42.6 h。窟内无公开实测已显式声明：窟内序列为文献参数化物理模型生成的合成标签，并以跨窟留一验证 5/6 通过检验外部效度。

## 一、需求分析

### 1.1 业务痛点：风险是"超阈时长"，不是"平均误差"

敦煌研究院的官方业务口径明确：**空气相对湿度一旦超过 62%，就可能加速壁画地仗层中的
盐分潮解**；配套的 CO₂ 预警阈值为 1500 ppm（樊锦诗 2013；郭青林 2026；汪万福公开表述）。
学术侧的阈值分三级（见 §1.3）。这三个阈值共同刻画的是同一件事：

> **损伤 ∝ 超阈的持续时间与反复次数**，而不是湿度的平均值。

这意味着一个预报系统哪怕平均误差很小，只要它**从不当湿度接近阈值**，在业务上就等于零。
本项目的第一项实验就是这一论断的直接实证（§3.1）。

### 1.2 能力缺口：文献自己把问题留在了桌上

*Heritage Science* 2022（DOI 10.1186/s40494-022-00805-3）用 XGBoost 预测室内相对湿度超限，
原文明确写道：

> "A desirable improvement of the model would be **predictions for periods longer than 24 h
> ahead**, still maintaining a high test accuracy."

并抱怨 "difficulties in obtaining good historical climate data sets"。**">24 h 多步预测"与
"数据稀缺"这两条未解问题，正是本项目直接接住的问题。**

### 1.3 需求的形式化：三个子问题

| # | 子问题 | 为什么是算法问题 |
|---|---|---|
| P1 | **目标变量不可观测** | 窟内湿度无公开实测，无法直接监督；只能通过物理代理间接定义 |
| P2 | **目标函数与决策错配** | 损伤 ∝ 超阈时长，而现有工作一律优化 RMSE/R² |
| P3 | **多步预报误差在极值处最大** | 24–72 h 推进的误差累积恰在最危险的尾部最严重 |

**三级业务阈值（逐级独立出处，构成本项目的风险判据）**

| 阈值 | 含义 | 出处 |
|---|---|---|
| **62%** | 业务预警线 | 敦煌研究院官方业务口径，配套 CO₂ 1500 ppm |
| **67%** | 可溶盐潮解起始 | Demas et al. 2015, DOI 10.1007/978-3-319-09000-9 |
| **75%** | 吸湿与渗透性突变 | npj Heritage Science 2025, DOI 10.1038/s40494-025-01756-1 |

### 1.4 需求侧政策依据

甘肃省气象局与敦煌研究院共建**文物保护气象服务联盟**；敦煌市已布设 **7 套区域自动气象站**
服务 **200 余座石窟**。即：**外场气象观测能力已经就位，缺的是把外场数据转化为窟内风险
的算法**。本项目正是补这一环。

## 二、AI 技术应用

### 2.1 技术路线总览

```
                    ┌──────────────────────────────────────────────┐
   外场公开数据 ───► │ L1  多时效概率预报（分位数）                  │
   (NASA POWER)     │     骨干：MLP / 可替换 LSTM、PatchTST         │
                    └───────────────────┬──────────────────────────┘
                                        │  室外分位数轨迹 (72h × 5要素 × Q分位)
                                        ▼
                    ┌──────────────────────────────────────────────┐
                    │ L2  延迟嵌入 Koopman/EDMD 输运算子            │
                    │     闭式解 · 可微 · 可解释                    │
                    │     室外轨迹 ──► 窟内 RH 风险代理             │
                    └───────────────────┬──────────────────────────┘
                                        │  窟内 RH 风险
                                        ▼
                    ┌──────────────────────────────────────────────┐
                    │ L3  风险对齐训练（本作品核心算法贡献）         │
                    │     twCRPS 阈值加权评分 + 算子导出权重         │
                    └───────────────────┬──────────────────────────┘
                                        ▼
                              三级决策：正常开放 / 限流 / 关闭
```

### 2.2 L2：延迟嵌入输运算子（可微物理代理）

**为什么需要算子层**：窟内无实测标签，只有物理模型生成的合成标签。若把逐时步推进的
物理模型直接接在预报网络后，会有两个问题——**难以高效反传**、**推理代价高**。
因此需要一个闭式解、可微、可解释的高速代理。

**理论依据**：Takens 嵌入定理与 HAVOK（Brunton et al., *Chaos as an intermittently forced
linear system*, Nat Commun 8, 2017, DOI 10.1038/s41467-017-00030-8）——在受迫系统中，
未被观测的标量可观测量可从被观测量的延迟坐标中重构。

**算子形式**：设外场驱动 :math:`x_t \in \mathbb{R}^d`，构造提升特征 :math:`\Psi(u_t)`：

- **演化**：:math:`\Psi(u_{t+1}) \approx K \Psi(u_t)`
- **读出**：:math:`\hat h_t = w^\top \Psi(u_t)`

:math:`K, w` 均由**岭回归闭式解**给出，**不含反向传播**。:math:`K` 的特征值谱给出
物理可解释的时间常数与衰减率。

**特征设计（每族对应明确物理量）**

| 特征族 | 维度 | 物理含义 |
|---|---|---|
| 快变延迟坐标 | 48 × 5 = 240 | 日循环与天气过程的高频响应 |
| 多尺度滑动均值 | 12 | 窟壁温度本质是室外气温的低通滤波结果。窗口 1/3/7/30/90/365 天 |
| Magnus 比值项 | 6 | 因 :math:`RH = q/q_{sat}(T)`，把温湿耦合非线性直接写进特征 |

共 **258 维**，**严格因果**（第 t 行只依赖 :math:`\le t` 时刻信息）。

### 2.3 L3：风险对齐训练

**方法**：Gneiting & Ranjan (2011, DOI 10.1198/jbes.2010.08110) 的阈值加权连续排序概率评分

```
twCRPS(F, y; v) = ∫ [ F(z) − 1{z ≥ y} ]² · v(z) dz      （积分遍历全体实数 z）
```

实现上采用等价的**加权分位数（pinball）损失**：
:math:`\mathcal{L} = \sum_k \omega_k \rho_{\tau_k}(y - q_k)`。

**本作品的改动**：让权函数成为**由输运算子导出的状态相关变量**

```
ω_k(t, h) = 1 + γ · σ( (ĥ_cave(t+h) − r) / s ) · (2·τ_k − 1)_+ · exp( −h / H_eff )
                 (   风险门控   )            (  上尾强调  )      (  时效衰减  )
```

⚠️ **本改动未通过预登记判据**，已降级处理，详见 §3.3。该失败**主动呈现**，不掩盖。

### 2.4 系统的工程约束：纯 CPU 可运行

算子层为闭式解（岭回归 / SVD），**全流程可在普通 CPU 上运行、无需 GPU、无 BPTT**。
这使系统可直接部署在景区边缘设备或研究机构的普通工作站上，符合文保行业算力现实。

## 三、实验与结果

### 3.1 目标函数错配的实证（本项目立论基础）

在标准 MSE 训练下：窟内 RH 的 **R² = 0.42**（看起来不错），
但**超阈事件 F1 = 0.000**——模型**从不预报任何一次超阈**
（预报最大值仅 **52.8%**，而阈值是 62%）。

| 训练目标 | pred_rate | pred_max | F1@62% | AUC@62% | 点 R² |
|---|---|---|---|---|---|
| A：MSE（现有全部工作） | **0.0000** | **52.8%** | **0.000** | 0.781 | 0.431 |
| B：MSE + twCRPS（本作品） | 0.0208 | 75.8% | **0.122** | **0.875** | **0.470** |
| C：twCRPS + 内生权重 | 0.0042 | — | 0.094 | 0.872 | 0.469 |

**B vs A 是实打实的增益**：F1 **0 → 0.122**，AUC **0.781 → 0.875**，
且逐点 R² **不降反升**（0.431 → 0.470）——风险对齐**没有牺牲**点精度。

### 3.2 与基线的对比（24 h 时效，62% 阈值，测试段 2021–2025）

| 模型 | AUC | F1 | 预警检出率 | 平均提前量 | 可部署 |
|---|---|---|---|---|---|
| [oracle] Persistence | 0.836 | 0.092 | — | — | ❌ 需窟内实测 |
| **Operator（本作品）** | **0.818** | **0.099** | **34.0%** | **42.6 h** | ✅ |
| RidgeDirect（无延迟嵌入） | 0.738 | 0.054 | — | — | ✅ |
| Climatology | 0.734 | 0.002 | — | — | ✅ |
| Persistence-operator | 0.500 | 0.025 | — | — | ✅ |
| **FirstOrderTransfer（初稿方案）** | **0.499** | **0.000** | **0.0%** | **从不预警** | ✅ |

**要点**：

1. 算子在 **48 h / 72 h 时效上 AUC 反超 oracle 持续性**（0.783 / 0.767 vs 0.749 / 0.709）。
2. **初稿方案的算法内核（文献标定一阶传递函数）被证伪**：AUC 与随机猜测无异（0.499），
   预警检出率为 0，且递归 72 步数值发散。

### 3.3 消融：完整特征配置确有贡献

**方法学要点**：不同消融的特征维度不同，共用正则系数时"某消融反超"可能只是正则强度错配
的伪象。因此**每个配置在验证段独立选择岭回归系数 β**。

| 配置 | β* | R² | AUC |
|---|---|---|---|
| [oracle] Persistence（不可部署） | — | 0.428 | 0.836 |
| Ablation-短延迟(12 h) | 1 | 0.536 | 0.826 |
| **Operator-Full（本作品）** | 1 | **0.543** | 0.818 |
| Ablation-无 Magnus 项 | 1 | 0.541 | 0.817 |
| Ablation-无慢变项 | 0.001 | 0.520 | 0.804 |
| Ablation-仅快变延迟 | 0.001 | 0.513 | 0.795 |
| RidgeDirect | — | 0.315 | 0.738 |

**结论**：完整特征配置在两个维度上都最优或接近最优，各消融均不优于它——
"多尺度慢变项 + Magnus 耦合项"的**物理动机特征设计确有贡献**。

### 3.4 读出层修正：极值压缩的诊断与处置

**诊断**：演示场景中真实窟内 RH 在 72 h 内升至 **89.0%**，而状态式线性读出只给 **34.8%**；
即便喂入**真实未来外场**（完美气象预报上界）也仅 **52.0%**——**62% 阈值因此永远够不到**。

**处置**：Koopman 特征保持不变，仅把读出层换成梯度提升树。

| 指标 | 线性岭回归 | GBDT 非线性 | 变化 |
|---|---|---|---|
| RMSE @24 h | 7.284 | **6.562** | −9.9% |
| **极值捕捉比 @24 h** | 0.592 | **0.682** | **+15.2%** |
| **AUC @75%（最危险档）@24 h** | 0.756 | **0.888** | **+13.2 pp** |
| AUC @75% @72 h | 0.717 | **0.804** | +8.7 pp |

**结论（如实陈述自身设计的取舍）**：闭式线性读出保住了可微性，代价是极值保真度。
最终采用**双轨读出**——GBDT 面向业务预报（精度与极值最优，仍为纯 CPU），
线性算子的谱与特征族权重面向物理解释与可微梯度链路。

### 3.5 跨窟外部效度验证

**设计**：**第 71 窟标定 → 第 87 窟检验**（另一洞窟、另一团队、另一套传感器，
标定时完全未使用）= 留一窟检验，用于反驳"合成标签闭环"的循环论证质疑。

| 指标 | 模型 | 第 87 窟实测 | 判定 |
|---|---|---|---|
| 窟内月均温范围 (°C) | [2.08, 22.34] | [3.0, 20.3] | ✅ |
| 窟内月均 RH 范围 (%) | [24.3, 40.1] | [22.7, 53.5] | ✅ |
| **年周期温度相位滞后** | **1.0 个月** | **1 个月** | ✅ |
| 日周期最低温滞后 | +71 min | +64 min | ✅ |
| 日周期最高温滞后 | +75 min | +20 min | ⚠️ 量级内 |
| 窟外月均 RH 范围 | [22.8, 39.3] | [16.3, 47.4] | ⚠️ 输入数据差异¹ |

¹ 差异来自驱动数据（NASA POWER 再分析 vs 现场气象站），非模型偏差。

**5/6 通过**。可支持"模型学到了传递结构的共性，而非过拟合单一洞窟"；
**不可**支持"可精确复现任意洞窟"。

### 3.6 真实洞穴观测的外部效度验证（ICCP）

§3.1–§3.4 的标签来自物理代理，为回应"合成标签闭环"的质疑，本节改用**完全独立的真实观测数据**：
以色列洞穴气候计划（ICCP，Zenodo `10.5281/zenodo.17505739`，CC-BY-4.0）在 12 个岩溶洞穴部署
42 台记录仪，2019-09-19 → 2021-07-04 逐小时记录气温与相对湿度。

**任务构造**：每个洞窟取近洞口受光区（`Lighting_Zone = Light`）与深处无光区（`Dark`）的记录仪
配对，**用受光区逐时 RH 驱动、预测深处逐时 RH**。该任务与本作品"室外 → 窟内"的架构同构，
但**不含任何物理模型、不含任何合成标签**。

**结果（测试段 20%，8 个有效洞窟）**

| 模型 | R² 中位数 | R² > 0 的洞数 | RMSE 中位数（RH 百分点） |
|---|---|---|---|
| Persistence（把洞口 RH 直接当深处，oracle 上界） | **−2.28** | — | — |
| FirstOrderTransfer（初稿方案：查表传递函数） | −0.255 | 3/8 | 7.18 |
| **Operator-Full（本作品）** | **+0.641** | **5/8** | **3.56** |

**三个结论**：

1. **洞口与深处的湿度是强解耦的**：Persistence 的 R² 中位数为 **−2.28**，即"直接把洞口 RH
   当作深处 RH"比"永远预测均值"还差。这从真实观测上说明了为什么初稿的查表传递函数不够——
   传播过程本身携带不可忽略的动力学。
2. **算子优于一阶传递函数：7/8 洞**，RMSE 中位数减半（7.18 → 3.56 个百分点）。
3. **但并非普遍有效**：Sela'（−6.41）、Murabba'at 2（−0.70）、Har Sifsof（−0.65）三洞的算子
   R² 为负，**如实报告**。Har Sifsof 深处 RH 均值 94.2%，Te'omim 恒为 100%（目标近似常数，
   R² 无定义，已由 `target_sd` 守卫剔除）——这类近饱和洞窟本方法不适用。

**边界声明（必须与结论同时阅读）**：ICCP 洞穴岩性为石灰岩/白云岩，与本作品标定的莫高窟
砾岩—砂岩不同；洞窟尺度与气候带（地中海 vs 干旱大陆性）亦不同。因此本节**只支持"输运算子
架构优于一阶传递函数"这一相对比较**，不外推到绝对精度，也不声称可直接迁移到莫高窟。

**同一数据给出的传递结构（附加证据）**：受光区 → 深处，日周期振幅比中位数 **0.184**
（范围 0.017–0.488），年周期振幅比中位数 **0.366**；日周期相位滞后中位数 **1163 分钟**
（约 19.4 h，仅当两端振幅均显著时才报告）。这与本作品物理模型"振幅衰减 + 相位滞后"的机制
定性一致。

### 4.3 方法学纪律（本项目可信度的核心）

1. **决策阈值在验证段标定**：事件率仅 1.28% 时，"点预报 ≥ 阈值"永不触发
   （实测**所有模型 F1 恒为 0**，含 oracle）。改为把预报值当**风险分数**，
   在验证段标定使报警率等于基准事件率的分位数，测试段只应用、**无信息泄露**。
2. **消融各自独立选 β**（§3.3）。
3. **发现并淘汰退化指标**：原始的"超阈持续时长 MAE"对全部时间窗取平均，
   使"永远不报警"的策略取巧。改为**事件条件化**并对"事件 ∪ 报警"窗口取均值，
   堵死"不报警"与"乱报警"两种取巧。
4. **诚实标注不可部署基线**：oracle 持续性需窟内实测输入，显式标注、不用于垫底比较。

## 五、应用成效

### 5.1 业务价值

| 能力 | 定量效果 |
|---|---|
| 超阈事件预警 | 24 h 检出率 **34.0%**，平均提前 **42.6 h** |
| 对比现有做法 | 初稿方案（文献传递函数）检出率 **0.0%**，即**完全无预警能力** |
| 长时效能力 | 48/72 h AUC **0.783 / 0.767**，**反超 oracle 持续性** |
| 精度与风险双赢 | 风险对齐后 F1 **0 → 0.122**，同时点 R² **0.431 → 0.470** |
| 部署成本 | **纯 CPU**，无 GPU、无 BPTT，可在普通工作站或边缘设备运行 |

**42.6 小时的提前量在文保场景中的意义**：足以支撑"提前一天关闭洞窟或启动除湿"的
一次完整管理决策周期，而现有文献方法的有效预报时效不超过 24 h。

### 5.2 可推广性

系统的核心是一个"**外场驱动 → 窟内代理 → 风险对齐**"的通用范式，
不依赖莫高窟的特有参数。已通过跨窟留一验证（第 71 窟标定 → 第 87 窟检验，5/6 通过）
证明其传递结构的可迁移性。

此外，**换气量以体积流量 Q（m³/h）而非换气次数 ACH 表达**——后者强依赖洞窟体积
（实测 ACH 仅来自 70–82 m³ 的小窟，而莫高窟大窟可达 1300 m³ 量级），Q 才是可迁移量。
这是**架构层面**而非参数层面的可迁移性设计。

可推广至：其他石窟寺（云冈、龙门、大足）、博物馆展陈微环境、岩画与土遗址保护。

### 5.3 社会效益

我国石窟寺分布广、监测条件差异大。本方案仅需**公开气象数据 + 普通 CPU**，
即可为缺乏窟内监测设备的中小型石窟提供风险预警能力，降低文保信息化的门槛。

## 六、总结与展望

### 6.1 工作总结

1. **问题重构**：把"文保应用"重构为"AI 算法问题"——
   在目标不可观测、判据为阈值+持续时间的条件下如何训练预报模型。
2. **算法贡献**：
   - **风险对齐训练**（twCRPS 替代 MSE）：F1 **0 → 0.122**，AUC **0.781 → 0.875**
   - **延迟嵌入输运算子**：可微、闭式、可解释的物理代理，AUC **0.818**
   - **物理动机特征设计**：逐配置调 β 后完整配置最优
   - **读出层极值修正**：极值捕捉比 **0.592 → 0.682**，最危险档 AUC **0.756 → 0.888**
3. **实证否定了初稿方案**：文献标定一阶传递函数 AUC **0.499**（等于随机）、检出率 **0%**。
4. **外部效度**：跨窟留一验证 5/6 通过；并在 **ICCP 12 个真实岩溶洞穴**的独立观测上，
   输运算子的 R² 中位数 **+0.641** vs 一阶传递函数 **−0.255**（7/8 洞占优，RMSE 减半）。

### 6.2 局限的诚实声明

| 局限 | 说明 |
|---|---|
| **窟内无公开实测数据** | 窟内序列为**文献参数化物理模型生成的合成标签**，非实测。这是本方案最大的攻击面。缓解：§3.5 跨窟留一验证 + §3.6 真实洞穴（ICCP）独立验证，二者都只支持**相对比较**，不支撑绝对精度 |
| 真实洞穴验证存在 3 个失败案例 | ICCP 中 Sela'、Murabba'at 2、Har Sifsof 三洞算子 R² 为负；近饱和洞窟（RH 恒 100%）不适用，已由守卫剔除 |
| 极值捕捉比仅 0.6~0.68 | 无人能真正抓住极端事件 |
| 绝对阈值决策偏乐观 | 62% 绝对阈值判级在当前精度下偏乐观，建议配合概率输出使用 |
| 物理模型偏差 | 窟内年均温比文献偏暖约 1.2 K；未建模长波冷却与游客短时脉冲 |
| 洞窟几何 | 模型代表中等规模旅游洞窟（约 67 m³），**不得外推到大窟** |

### 6.3 后续工作

1. **文献图版数字化**：用 WebPlotDigitizer 数字化已发表曲线做留一窟交叉验证。
2. **接入深度时序骨干**（LSTM / PatchTST / iTransformer）与算子并联，
   检验"物理代理 + 深度骨干"的复合增益。
3. **概率化决策**：由分位数输出直接给出"超阈概率"，替代绝对阈值判级。
4. **真实窟内实测接入**：与文保单位合作部署窟内记录仪，把 ICCP 式的验证
   真正做在莫高窟上，检验不可迁移的绝对精度。

## 附录 D：数据真实性声明

- 本作品的**窟内温湿度序列为基于文献参数化物理模型生成的合成标签
  （physics-derived synthetic labels），不是实测数据**。
  原因是莫高窟及中国石窟的窟内温湿度**无公开实测数据集**。
- 外场驱动数据为 **NASA POWER 再分析资料**（MERRA-2 及偏差订正），
  **不是站点观测**。敦煌国家气象站（ISD 52418）**2023-04-28 之后停止上报**。
- 合成标签闭环**仅用于算法开发**；泛化性由跨窟留一验证（§3.5，5/6 通过）
  与待完成的 ICCP 真实洞穴数据验证两条独立链路检验。
- 所有物理参数均标注文献出处与 DOI（附录 C）。
