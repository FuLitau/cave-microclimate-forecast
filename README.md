# 石窟天盾：风险对齐的窟内微气候预报

> 用**室外公开气象数据**，预报**石窟窟内**未来 24–72 小时的相对湿度风险。
> 面向"第八届 AIC 全球校园人工智能算法精英大赛 · 智慧气象"主题赛。
>
> **代码仓库**：<https://github.com/FuLitau/cave-microclimate-forecast>（Public）

**一句话**：把"预测窟内温湿度"这个文保应用问题，重构成一个**算法问题**——
在**目标不可观测、标签稀缺、决策不可逆**的条件下，训练一个**可微的物理代理**，
并让训练目标函数与**"阈值 + 持续时间"型损伤判据**对齐。

---

## 1. 问题：初稿的三个病灶

| 病灶 | 具体表现 |
|---|---|
| **P1 目标不可观测** | 窟内温湿度**没有公开实测数据集**，且与本项目无合作文保单位。任何"预测窟内"的方案都必须先回答"标签从哪来" |
| **P2 目标函数错配** | 初稿的最小二乘训练在窟内 RH 上能到点 R²=0.59，但**超阈召回率仅 0.047**——漏报 95% 以上的超阈事件（更正：旧稿「从不预报超阈 / 预测最大值仅 52.8%」经重标定重跑后不再成立）。壁画盐害由**阈值 + 持续时间**决定，而非均方误差 |
| **P3 多步误差在极值最大** | 24–72 h 时效的误差恰在**最危险的湿季峰值**处最大，而这正是唯一需要预警的时刻 |

初稿的算法核心是一个**查表式一阶传递函数** `RH_in = a·RH_out(t−Δ) + b`：
`a`、`Δ` 是从文献摘抄的常数。**这不是学习，是查表。**
本项目的实验把它作为基线正式证伪（见第 4 节）。

---

## 2. 方法：三层链路

```
室外公开气象（POWER / NASA）        L1  多步外场预报
        │
        ▼
延迟嵌入 Koopman/EDMD 输运算子      L2  可微物理代理      ← 创新点 2（模型级）
  258 维严格因果特征                  Ψ(u_{t+1}) ≈ K·Ψ(u_t)
        │                                 ĥ_t = wᵀ·Ψ(u_t)
        ▼
阈值加权评分规则 twCRPS             L3  风险对齐训练      ← 创新点 1（模型级）
  三级阈值 62% / 67% / 75%
```

- **L2 输运算子**：把外部驱动延迟嵌入到高维可观测量空间，用**岭回归闭式解**学一个线性输运算子。
  特征三族共 **258 维**：快变延迟（240）+ 慢变滑动均值（12）+ Magnus 温湿耦合比值（6）。
  **全流程无梯度下降、无 BPTT、纯 CPU 可运行。**
- **L3 风险对齐**：用**阈值加权连续排序概率评分（twCRPS）**替代 MSE，
  使损失函数直接对应"超阈 + 持续"的损伤判据。三级阈值分别取自
  敦煌研究院官方业务口径（62%）、Demas 2015 潮解起始（67%）、npj Heritage Science 2025 吸湿突变（75%）。

## 3. 关键结果（测试段 2021–2025）

**24 h 时效，62% 阈值**

| 模型 | AUC | F1 | 预警检出率 | 平均提前量 |
|---|---|---|---|---|
| Persistence（需窟内实测，**不可部署**） | 0.836 | 0.092 | — | — |
| **输运算子（本作品）** | **0.860** | **0.127** | **35.1 %** | **46.7 h** |
| 一阶传递函数·静态传递（初稿的可部署化形式） | 0.824 | 0.076 | 29.8 % | 42.5 h |
| RidgeDirect（直接回归） | 0.739 | 0.053 | — | — |
| Climatology（可部署） | 0.734 | 0.002 | — | — |
| 一阶传递函数·**递归实现**（初稿原样） | 0.500 | 0.000 | 0.0 % | 从不预警 |
| 一阶传递函数·**原文无自回归形式** | **0.896** | 0.052 | — | — |

⚠️ **必须连带披露的一条**：初稿传递函数的**原文形式 AUC 达 0.896，高于本作品**。
它的问题**不是排序能力，而是绝对量级被压缩**——校准出的决策阈值落在 48.9%（业务阈值是 62%），
召回率只有 0.0375，F1 因此仅 0.052。诚实表述是「抓到了形状、丢掉了量级」，
而不是「与随机无异」——后者只对**递归实现**成立（极点 a = 1.000920 > 1，必然饱和）。

- 算子在 **48 h / 72 h 的 F1（0.098 / 0.058）仍高于 oracle（0.064 / 0.043）**。
- 把读出层从线性岭回归换成梯度提升（特征不变）：AUC@62% **0.819 → 0.883**，
  最危险的 75% 档 **0.759 → 0.900**，极值捕捉比 **0.592 → 0.689**。
- ⚠️ **在"超阈持续时长"上本作品不占优**（条件时长 MAE 5.27 h vs oracle 4.68 h），
  详见 `docs/01_技术路线.md` §6.6——时长精度必须与检出率联合阅读。
- 风险对齐训练的收益：F1 **0.072 → 0.141**（验证/测试 × 3 时效六格全部提升），
  AUC **0.862 → 0.901**（62% 口径下六格全部为正增益；三档平均口径下 5 胜 1 负，验证段 48 h 由 0.881 微降至 0.868）。

**外部效度：三条独立链路**

| 链路 | 设计 | 结果 |
|---|---|---|
| 跨窟留一 | 第 71 窟标定 → 第 87 窟检验（另一洞窟、另一团队、另一套传感器） | **5/6 项通过** |
| 同窟同期实测 | 第 71 窟 2019–2021 实测（Gong et al. 2025）；**温度统计量从未参与标定** | 窟内年均气温差 **0.45 K**、最高差 0.22 K；**冷端极值低估 5.35 K**（如实报告） |
| **真实洞穴（ICCP）** | 12 个岩溶洞穴，受光区观测 → 深处 RH 传递，**不含任何合成标签** | 算子 R² 中位数 **+0.641** vs 一阶传递函数 **−0.255**（**7/8 洞占优**，RMSE 7.18 → **3.56**） |

ICCP 最有价值的发现：oracle Persistence（"直接把洞口 RH 当作深处 RH"）的
R² 中位数为 **−2.28**——**比永远预测均值还差**。
即洞口与深处湿度**强解耦**，传播过程本身携带不可忽略的动力学。
这正是初稿查表式传递函数失效的**物理原因**（此前只有 AUC 的经验证据）。

交付前还自查出并修复了一个标定流程缺陷：初版只用外场前 30 天作初值，而 5 m 岩体
导热链时间常数是月–年量级，导致窟内 RH 最高虚高 14.7 pp；加 2 年自旋期后降至 2.50 pp。

## 4. 快速开始

```bash
pip install -r code/requirements.txt          # 需要 Python >= 3.12

python code/smoke_cave.py                     # 物理模型冒烟自检（断言式）
python code/src/data/power.py                 # 下载 NASA POWER 逐小时气象（2001–2025）
python code/experiments/calib_cave_params.py  # 用文献实测传递比标定物理模型
python code/experiments/derisk_02_multihorizon.py   # 主结果：多时效基线与消融
python code/experiments/exp03_risk_aligned.py       # 风险对齐 A/B/C 对照

python tools/fetch_iccp.py                    # 下载 ICCP 真实洞穴观测（Zenodo）
python code/experiments/validate_iccp.py      # 真实洞穴外部效度验证
python code/experiments/validate_crosscave.py # 跨窟留一验证

python code/src/web/app.py                    # 本地看板 http://127.0.0.1:5000
```

**全流程可在纯 CPU 上运行**（本项目有意不使用 GPU）。

## 6. 数据与诚信声明

- **窟内温湿度不存在公开实测数据集。** 本项目的窟内标签由**文献参数化的物理模型生成**
  （physics-derived synthetic），**不是实测值**。所有性能数字反映的是
  "算法在物理代理上的能力"，**不能直接等同于现场精度**。这是本方案最大的局限，已显式声明。
- 驱动数据为 NASA POWER **再分析**产品（`code/data/interim/power_hourly_mogao_2001_2025.csv`，
  219,144 行 × 10 列，2001-01-01 → 2025-12-31，缺测 0），**不是站点观测**。
- ICCP 真实洞穴数据（Zenodo `10.5281/zenodo.17505739`，CC-BY-4.0）为**独立真实观测**，
  但其岩性（石灰岩/白云岩）与气候带（地中海气候）与莫高窟（砾岩—砂岩、干旱大陆性）不同，
  因此**只支持"架构相对优劣"的比较，不支撑绝对精度**。
- **全部物理参数均标注文献 DOI**，见 `code/src/physics/cave_model.py::PARAM_SOURCES`
  与 `docs/06_佐证材料.md`。
- 本项目保留**被实验否定的设计**记录：`K^h` 逐步滚动演化、twCRPS 内生权重、点预报判超阈
  ——详见 `docs/01_技术路线.md` 附录与 `docs/06_佐证材料.md` 第五节。

## 7. 已知局限

| 局限 | 说明 |
|---|---|
| 窟内无实测标签 | 最大攻击面。三条外部链路都只支持相对比较 |
| 极值捕捉比仅 0.61–0.69 | 无人能真正抓住极端事件 |
| 绝对阈值决策偏乐观 | 62% 绝对阈值判级在当前精度下偏乐观 |
| 物理模型年阻尼偏强 | 同窟同期对照中**冷端极值低估 5.35 K**（模型 −1.35 °C vs 实测 −6.7 °C），年极差比 0.468 vs 文献 0.559；根因是未建模夜间长波辐射冷却。同时报告：窟内年均气温差仅 0.45 K，且温度统计量从未参与标定 |
| 洞窟几何 | 模型代表中等规模旅游洞窟（约 67 m³），**不得外推到大窟** |
| ICCP 有 3 个失败洞 | Sela'、Murabba'at 2、Har Sifsof；近饱和洞窟不适用 |

## 8. 被否定的设计（保留记录）

科研诚信要求负结果同样留档。本项目有三处**预登记判据未通过**的设计，
它们**没有被删掉改写**，而是原样保留在文档与附录中：

1. **twCRPS 内生权重**：预登记判据"只有 C 显著优于 B 才证明贡献来自内生权重本身"，
   实测 **18 组中仅 2 组通过**（验证段与测试段各 1/9，`code/results/exp03_verdict.csv`）。
2. **`K^h` 逐步滚动演化**：多尺度滑动均值是**外生汇总量**而非不变 Koopman 可观测量，
   强行演化破坏信号（`diag_rollout.csv`：h=24 rollout +0.31 vs 直接读出 +0.55，全时效劣于直接读出）。
3. **点预报直接判超阈**：实测 MSE 点预报召回率仅 0.047（漏报 95% 以上），
   是**指标与预报表示不匹配**——已改为把预报值当风险分数、在验证段标定决策阈值。
