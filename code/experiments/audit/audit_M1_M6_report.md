## 需要修复的具体建议

1. **M1（最高优先，读者可直接踩到）**：给 `calib_verify.py` 补上与 `calib_cave_params.py` 一致的自旋期（`drive = outdoor_all.loc[f"{2010-SPINUP_YEARS}-01-01":EVAL_END]`，默认 2 年、`CALIB_SPINUP_YEARS=0` 可关），并在脚本输出里打印「自旋期 = N 年 / 无自旋期」；`README.md:37-38` 的复现命令旁注明该脚本的口径；把 `README.md:173-174` 的「已修复」明确限定为 `calib_cave_params.py` 与 `calib_cave71_compare.py`（`calib_cave71_compare.py:73-74` 已默认自旋 2 年）。
2. **M2**：把 `code/src/operator/transport.py:56` 与 4 处实验的 `"PS"` 改为 `"PSC"`；若因历史结果不复现而暂不改，则删掉 `power.py:84` 的死常量 `PRESSURE_VARIABLE`，并把 `power.py:33-34` 的「不要用 PS」改成带量化影响的表述（实测 ΔR² ≤0.002、ΔAUC ≤0.001），消除注释与实现的直接冲突。
3. **M3**：`exp03_risk_aligned.py` 用 2020 验证段做早停/选 beta（当前 `ridge_beta=10.0` 硬编码于 L277，与 derisk_02 的验证段网格不一致），至少在日志打印 val 指标；把 `duration_err`（L245-249）换成 derisk_02 的 `duration_metrics(..., cut=...)` 事件条件化口径，并在日志注明旧口径「从不报警即最优」的退化性（A 模式 0.2834 = base_rate×24）。
4. **M4**：跨脚本统一为「验证段网格搜索」并落盘 beta 约定（每个结果表旁注明 beta*），或至少在每个实验脚本的 docstring 里写明所用 beta 与其来源；README 正文避免把不同脚本/数据集/ beta 约定的数字并置成一条论证链。
5. **M5**：把 derisk_02 的 `FirstOrderTransfer` 行换成公平协议（非递归直接传递 P3，或逐小时/每 24 h 重锚），并把 P0 的退化机理写进日志（`a=1.00092>1`、clip 后 99.84% 落 0、AUC 恒为 0.5）；同时**如实报告 P3 在 AUC 上反超算子（0.8957 vs 0.8178）**，否则「算子 AUC 反超 oracle」的叙事有选择性报告之嫌。ICCP 链路的 FOT 已是非递归的直接传递（`validate_iccp.py:204-223`），可继续作为「初稿方案失效」的正当证据（R² −0.255 vs +0.641）。
6. **M6**：在 derisk_02 日志与 README 补上消融判读：Magnus 族验证段 −0.0038（负）、测试段 +0.0015，量级远小于 `仅快变延迟`（−0.031）与 `短延迟12h`（−0.016）的差距；若要保留「三族齐备」的表述，需补一个逐块 bootstrap 之类的显著性检验，否则应改写为「慢变项贡献最大（−0.031 差距），Magnus 项贡献不显著」。
