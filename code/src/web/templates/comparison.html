两个必须注意的评测口径：
① 点预报不能用于事件检测——事件率仅约 1%，"点预报 ≥ 阈值"永不触发， 实测所有模型 F1 恒为 0（含 oracle）。因此决策阈值在验证段标定、测试段只应用，无信息泄露。
② Persistence(oracle) 不可部署——它需要窟内实测作为输入，而本场景没有窟内传感器。 它只作天花板参照，不用于垫底比较；可部署对比以 Climatology 与 Persistence-operator 为准。
